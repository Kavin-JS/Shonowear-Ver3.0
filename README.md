# ShonoWear v2.0

ShonoWear v2.0 is an improved version of the original ShonoWear project — a static e-commerce storefront built with HTML, CSS, and JavaScript.

The goal of this version is to improve UI design, layout consistency, and front-end structure while demonstrating clean web development fundamentals.

## Features
- Responsive product grid layout
- Navigation-based shopping interface
- Product listing pages
- Improved UI styling
- Static deployment ready (GitHub Pages)
